# Landing Page Project

Cloned and restructured from iironiicmedia.com.

## Project Structure

```
/src/assets/images    — Page images and portfolio photos
/src/assets/icons     — App icons and favicons
/src/assets/fonts     — Web fonts (WOFF2)
/src/components       — Reusable UI components
/src/styles           — Global CSS and CSS variables
/src/utils            — JavaScript bundles
/src/pages/work       — Portfolio page HTML references
/public               — Static assets (favicon, robots.txt)
```

## Getting Started

```bash
npm install
npm run dev
```
